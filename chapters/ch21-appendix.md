# Chapter 21: Appendix

## Core Idea
Reference material: command-line options, complete keyboard shortcut list, MuseScore 3→4 upgrade notes, glossary, music fonts, and the percussion MDL updates.

## Frameworks Introduced
- **Command-line options**: batch operations — convert files, export, run plugins. `musescore --help`.
- **All keyboard shortcuts**: Preferences→Shortcuts; search by action.
- **Upgrade from MuseScore 3.x**:
  - v4 is a new major version; old .mscz open but re-engraved.
  - Synthesizer panel removed; sounds per-score in Mixer.
  - v3 plugins are not compatible; port to v4 QML.
  - New file format (still .mscz).
- **Glossary**: terms used throughout the handbook.
- **Music fonts**: Emmentaler (default), Bravura, Gonville, etc. Format→Style→Score→Music font.
- **MDL percussion changes**: MuseScore Drum Language updates in v4.

## Key Takeaways
1. CLI: `musescore --help` for batch export.
2. Shortcuts fully remappable in Preferences→Shortcuts.
3. v3→v4: expect re-engraving, new Mixer, no Synthesizer, no v3 plugins.
4. Music fonts switchable in Style.
