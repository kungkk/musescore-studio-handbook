# Chapter 20: Support & Troubleshooting

## Core Idea
Help resources: built-in Handbook (F1), musescore.com support forum, GitHub issues. Common fixes: reset preferences, reinstall Muse Sounds, check audio device, update graphics drivers.

## Frameworks Introduced
- **Help resources**:
  - Handbook: F1 or Help menu.
  - musescore.com/support forum.
  - GitHub issues for bugs.
- **Common troubleshooting**:
  - **No sound**: check Mixer (M), audio device in Preferences→Audio & MIDI, Muse Sounds installed.
  - **Crashes on launch**: reset Preferences (Edit→Preferences→Reset), reinstall.
  - **Slow playback**: lower buffer size, use Muse Sounds vs SFZ, disable VST plugins.
  - **Score looks wrong after v3→v4 upgrade**: v4 re-engraves; adjust layout.
  - **Missing fonts**: reinstall music fonts / MuseHub.
- **Upgrading from earlier versions**: see Appendix.

## Key Takeaways
1. F1 opens the handbook.
2. No sound → check Mixer + audio device + Muse Sounds.
3. Reset Preferences if unstable.
4. v4 re-engraves old scores; expect layout changes.
