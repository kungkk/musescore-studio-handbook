# Chapter 13: Alternative Notation

## Core Idea
MuseScore supports custom staff types, mensural (early music) notation, slash notation (rhythm chords), and custom clefs. Most alternative notation is achieved by customizing staff type, noteheads, and clefs rather than switching modes.

## Frameworks Introduced
- **Custom staff types**: Staff/Part properties → Staff type; set number of lines, clef, notehead.
- **Mensural notation**: early-music note shapes; noteheads palette.
- **Slash notation**: rhythm slashes above chord symbols; used in lead sheets / comping.
- **Custom clefs**: Clefs palette → More → create custom clef.
- **Small/cue staves**: Staff properties → Small staff for cue passages.
- **Tab types for other fretted instruments**: ukulele, lute, banjo — choose from staff type list.

## Key Takeaways
1. Custom staff types cover most alternative notation needs.
2. Slash notation pairs with chord symbols for comping.
3. Cue staves = small staff.
4. Custom clefs via Clefs palette → More.
