# Chapter 12: Idiomatic Notation — Harp & Percussion

## Core Idea
Harp uses standard notation with pedal-change diagrams. Percussion uses **drumset staff** (unpitched, line/space per instrument) or **pitched percussion** (timpani, mallets). Drum input via MIDI drum pad or percussion palette.

## Frameworks Introduced
- **Harp**:
  - Pedage (pedal change) diagrams: Harp palette; shows ♰/♱ pedal settings.
  - Glissando lines: Arpeggios & glissandi palette.
- **Percussion**:
  - **Drumset staff**: each line/space = a drum/cymbal; notehead shape indicates instrument.
  - **Pitched percussion**: timpani, xylophone, marimba — treated as normal pitched instruments.
  - **Unpitched percussion**: snare, bass drum, cymbals — percussion staff type.
- **Drum input**:
  - MIDI drum pad: each note maps to a drum (editable in drumset staff properties).
  - Percussion palette: drag notehead onto the correct line/space.
- **Rolls**: measured/unmeasured rolls on mallets and timpani; Tremolo palette.
- **Appendix: MDL percussion changes** — MuseScore Drum Language updates.

## Key Concepts
- **Pedage** — harp pedal change diagram.
- **Drumset staff** — line/space = unpitched instrument.
- **Roll** — repeated-note tremolo on percussion.

## Key Takeaways
1. Harp pedal diagrams from Harp palette.
2. Drumset staff: each line/space = a drum; notehead = instrument.
3. MIDI drum pads map to instruments; mapping editable in staff properties.
4. Rolls via Tremolo palette.
