# Chapter 10: Idiomatic Notation — Keyboard

## Core Idea
Piano/keyboard scores use grand staff (treble+bass, braced). **Pedal lines** (sustain pedal) come from the Lines palette. **Cross-staff beaming** moves beams across the brace. **Accordion** has right-hand/left-hand button/keyboard configurations.

## Frameworks Introduced
- **Grand staff**: two staves braced together; piano template sets this up.
- **Pedal markings**:
  - Lines palette → sustain pedal line (pressed/released).
  - Drag to set extent; pedal marks show as vertical bracket or text.
  - Playback: pedal line affects sustain in MIDI.
- **Cross-staff notation**:
  - Select a note → Properties → *Move to staff above/below*.
  - Beams re-flow across the brace.
- **Arpeggio markings**: Arpeggios & glissandi palette; wavy line across a chord.
- **Accordion**: instrument family includes various button/keyboard configurations; left-hand bass/chord buttons notated on lower staff.
- **Piano fingerings**: Add → Text → Fingering; numbers 1–5.

## Key Concepts
- **Grand staff** — treble + bass braced (piano).
- **Pedal line** — sustain pedal on/off bracket.
- **Cross-staff** — note/beam spanning the brace.

## Mental Models
- Think of pedal lines as "sustain on/off" brackets.
- Think of cross-staff as "this note belongs visually on the other staff."

## Key Takeaways
1. Grand staff = treble+bass braced; piano template pre-wires it.
2. Pedal lines from Lines palette; drag to set on/off.
3. Cross-staff via Properties → Move to staff above/below.
4. Fingerings are text (1–5).
