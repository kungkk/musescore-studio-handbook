# Glossary — MuseScore Studio Handbook

**Accidental** — sharp/flat/natural sign; prefix with `-`/`+`/`=` during note entry. (Ch 4, Ch 7)
**Ambitus** — range marking at start of a staff. (Ch 7)
**Anacrusis / Pickup measure** — incomplete first measure. (Ch 3, Ch 6)
**Articulation** — staccato, tenuto, accent, fermata, etc. (Ch 8)
**Autoplace** — automatic collision avoidance for notation elements. (Ch 15)
**Barline** — single/double/repeat/bold line at measure boundaries. (Ch 6)
**Beam groups** — how eighth/sixteenth notes are grouped; defined per time signature. (Ch 6)
**Braille** — screen-reader accessible notation; F-D-S / J-K-L key input. (Ch 2)
**Chord symbol** — harmonic shorthand (Dm7, G7); Ctrl+K. (Ch 14)
**Courtesy accidental/key/time signature** — reminder at system break. (Ch 6, Ch 7, Ch 8)
**Cue staff** — small staff for cue passages. (Ch 13, Ch 5)
**Cutaway** — hide empty measures on a staff. (Ch 5)
**D.C. (da capo)** — jump to start. (Ch 9)
**D.S. (dal segno)** — jump to Segno marker. (Ch 9)
**Dynamics** — p, mf, ff; Ctrl+D. (Ch 8)
**Enharmonic respell** — J toggles C♯↔D♭. (Ch 7)
**Figured bass** — numbers below bass note. (Ch 14)
**Fine** — end marker after D.C./D.S. al Fine. (Ch 9)
**Frame** — horizontal/vertical box for titles/images. (Ch 15)
**Fretboard diagram** — chord box for guitar. (Ch 11)
**Grand staff** — treble+bass braced (piano). (Ch 10)
**Hairpin** — cresc./dim. line; `<` / `>`. (Ch 8)
**Linked staff** — two staves sharing notation (notation + tab). (Ch 5, Ch 11)
**Melisma** — one syllable over multiple notes. (Ch 14)
**Measure repeat** — symbol meaning "repeat previous bar(s)." (Ch 9)
**MIDI input pitch** — written vs sounding for transposing instruments. (Ch 17)
**Multimeasure rest** — collapsed empty bars with count. (Ch 6)
**Muse Sounds** — MuseScore's sample libraries. (Ch 17)
**Notehead** — shape of note; normal/diamond/cross/slash. (Ch 7)
**Pedage** — harp pedal-change diagram. (Ch 12)
**Pickup measure** — see Anacrusis.
**Properties panel** — left-side settings for selected element (formerly Inspector). (Ch 1, Ch 4)
**Rehearsal mark** — Ctrl+M; A/B/C or 1/2/3. (Ch 14)
**Segno** — jump destination marker. (Ch 9)
**Slur** — legato phrase across different pitches. (Ch 8)
**SoundFont** — .sf2/.sf3 sample bank. (Ch 17)
**Spatium (sp)** — staff space; master scale unit. (Ch 15)
**Staff type** — standard, tablature, percussion, custom. (Ch 5, Ch 11, Ch 12, Ch 13)
**System text** — applies to all instruments. (Ch 14)
**System markings** — tempo, rehearsal marks, voltas; can be duplicated vertically. (Ch 5)
**Tablature (tab)** — fret numbers on string lines. (Ch 11)
**Tempo marking** — ♩=BPM; sets playback. (Ch 14, Ch 17)
**Tie** — connects same-pitch notes; T. (Ch 4, Ch 8)
**Tuplet** — 3:2 triplet, etc. (Ch 6)
**Volta** — numbered ending bracket (1st/2nd time). (Ch 9)
**Voice** — independent rhythmic layer on a staff (up to 4). (Ch 4)
**VSTi** — virtual instrument plugin. (Ch 17)
